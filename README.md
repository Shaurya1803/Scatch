# Scatch - E-Commerce Website

Live Demo: https://scatch-8qf6.onrender.com/

Scatch is a full-stack e-commerce web application for buying and selling bags and accessories.

## Features

- User Registration and Login
- Product Listing
- Shopping Cart
- Admin Panel for Product Management
- Responsive User Interface

## Tech Stack

- Node.js
- Express.js
- MongoDB
- EJS
- Tailwind CSS

## Installation

1. Clone the repository

```bash
git clone https://github.com/Shaurya1803/Scatch.git
cd Scatch
```

2. Install dependencies

```bash
npm install
```

3. Create a `.env` file and add:

```env
MONGODB_URI=your_mongodb_connection_string
JWT_KEY=your_secret_key
```

4. Start the application

```bash
npm start
```

5. Open your browser and visit:

```text
http://localhost:3000
```
